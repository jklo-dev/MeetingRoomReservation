# AGENTS.md

Las instrucciones completas de trabajo de este proyecto **no** están en este archivo.

Antes de analizar, planificar, especificar o modificar cualquier parte del proyecto, lee
obligatoriamente:

- [`meetroom_local_config/AGENTS.md`](meetroom_local_config/AGENTS.md) — descripción del
  proyecto, arquitectura, tecnologías verificadas, comandos y reglas operativas.
- [`meetroom_local_config/constitution.md`](meetroom_local_config/constitution.md) —
  principios permanentes de diseño, planificación, implementación y validación.

Estos archivos están en un directorio local y no se cargan de forma
automática: deben consultarse de manera explícita al inicio de cada tarea.

Las especificaciones de funcionalidades viven en `meetroom_local_config/specs/`.
